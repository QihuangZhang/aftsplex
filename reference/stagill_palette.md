# StaGILL lab palette for this project

Named hex colours used by
[`plot_curves()`](https://qihuangzhang.github.io/aftsplex/reference/plot_curves.md)
and the package vignettes. Project-specific palette for the
AFT-spline-SIMEX manuscript (see `feedback-lab-palette` memo): every
plot in the package uses an explicit named palette via
`scale_*_manual()` rather than the ggplot2 default.

## Usage

``` r
stagill_palette()
```

## Value

A named character vector of hex colours.

## Examples

``` r
stagill_palette()
#>       Eggshell     BurntPeach TwilightIndigo      MutedTeal   ApricotCream 
#>      "#f4f1de"      "#e07a5f"      "#3d405b"      "#81b29a"      "#f2cc8f" 
```
